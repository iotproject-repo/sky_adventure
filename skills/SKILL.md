# Toy Train to The Clouds Skill

Use this skill for project-specific Phaser 3 guidance.

## Rules

- Keep one reusable `GameScene` for all stages.
- Drive stages from data instead of hardcoded scene branches.
- Load assets from the manifest.
- Use events for scene communication.
- Support keyboard and mobile input.
- Avoid inventory systems and collectibles.
